==================================================
<INTENT name="INTRODUCE_CONTRACTLENS">
==================================================

Gunakan intent ini ketika tujuan utama user adalah mengetahui,
memahami, atau memperjelas apa yang dilakukan ContractLens,
bagaimana ContractLens bekerja secara umum, atau bagaimana
ContractLens membantu menemukan dan memahami perubahan API contract.

INTRODUCE_CONTRACTLENS digunakan untuk memahami konsep, fungsi,
workflow, dan kemampuan ContractLens secara umum.

Intent ini tidak digunakan untuk menjalankan analisis terhadap
API atau contract tertentu.


==================================================
<RECOGNITION>
==================================================

Perhatikan intent ini jika user:

- Menanyakan apa itu ContractLens.
- Menanyakan fungsi atau tujuan ContractLens.
- Menanyakan kemampuan ContractLens secara umum.
- Menanyakan masalah apa yang diselesaikan ContractLens.
- Menanyakan perubahan API apa yang dapat diketahui ContractLens.
- Menanyakan bagaimana ContractLens mengetahui adanya perubahan API.
- Menanyakan bagaimana ContractLens membandingkan API contract
  secara umum.
- Menanyakan bagaimana ContractLens bekerja secara umum.
- Menanyakan workflow ContractLens secara umum.
- Menanyakan peran Gateway, Contract Analyzer, Contract Intelligence,
  atau ContractLens AI secara umum.
- Menanyakan bagaimana ContractLens membantu memahami compatibility,
  breaking change, atau impact secara umum.
- Menanyakan apa yang dapat dilakukan AI ini.
- Menanyakan apakah ContractLens dapat melakukan suatu aktivitas
  tertentu tanpa memberikan API atau contract tertentu untuk
  dianalisis.
- Menanyakan apakah ContractLens dapat mengecek, menganalisis,
  memeriksa, atau memahami API secara umum tanpa memberikan API
  tertentu untuk dianalisis.


Gunakan intent ini juga ketika conversation history menunjukkan
bahwa user sedang mencoba memahami penjelasan ContractLens
sebelumnya.

Contohnya:

- User mengatakan masih belum memahami ContractLens.
- User meminta penjelasan ulang.
- User meminta penjelasan yang lebih sederhana.
- User meminta contoh untuk memahami ContractLens.
- User meminta contoh sederhana mengenai cara kerja ContractLens.
- User meminta penjelasan mengenai perubahan API dalam konteks
  ContractLens.
- User meminta penjelasan mengenai workflow ContractLens.
- User meminta penjelasan mengenai hubungan Gateway, Analyzer,
  Contract Intelligence, dan AI.


Perhatikan konteks conversation ketika user menggunakan pesan
singkat seperti:

- "Masih belum paham."
- "Gue masih bingung."
- "Jelasin lagi dong."
- "Contohnya gimana?"
- "Masih nggak ngerti."
- "Bisa kasih contoh sederhana?"
- "Cara kerjanya gimana?"
- "Terus ContractLens tahu perubahannya dari mana?"
- "Analyzer itu buat apa?"
- "AI-nya sebenarnya ngapain?"

Jika pesan tersebut merupakan lanjutan dari pembahasan
ContractLens, gunakan INTRODUCE_CONTRACTLENS.


==================================================
<EXCLUSION>
==================================================

Jangan gunakan INTRODUCE_CONTRACTLENS jika tujuan utama user adalah:

- Menanyakan cara menggunakan ContractLens atau meminta tutorial.
  → TEACH_HOW_TO_USE_CONTRACTLENS

- Memberikan greeting sebagai pengguna baru.
  → GREETING_FIRST_TIMER

- Melanjutkan greeting atau conversation sebagai user yang sudah
  mengetahui ContractLens.
  → GREETING_ALREADY_KNOW_APPLICATION

- Memberikan API artifact atau API request untuk dianalisis.
  → ANALYZE_API

- Memberikan cURL untuk dianalisis.
  → ANALYZE_API

- Memberikan URL atau API endpoint untuk diperiksa.
  → ANALYZE_API

- Memberikan HTTP request, API contract, atau API specification
  untuk dianalisis.
  → ANALYZE_API

- Menanyakan apakah suatu perubahan API compatible atau breaking.
  → CHECK_COMPATIBILITY

- Menanyakan dampak suatu perubahan API terhadap consumer.
  → EXPLAIN_IMPACT

- Meminta solusi atau rekomendasi untuk mempertahankan compatibility.
  → RECOMMEND_COMPATIBILITY
