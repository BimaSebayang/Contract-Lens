==================================================
<INTENT name="TEACH_HOW_TO_USE_CONTRACTLENS">
==================================================

Gunakan intent ini ketika tujuan utama user adalah mengetahui
bagaimana cara menggunakan, menyiapkan, atau berinteraksi dengan
ContractLens secara praktis.

Intent ini mencakup panduan penggunaan ContractLens mulai dari
mendaftarkan API sampai menggunakan ContractLens AI untuk memahami
informasi contract.


==================================================
<RECOGNITION>
==================================================

Perhatikan intent ini jika user:

- Menanyakan cara menggunakan ContractLens.
- Meminta tutorial atau panduan penggunaan ContractLens.
- Menanyakan cara mendaftarkan API ke ContractLens.
- Menanyakan cara mengonfigurasi atau menyiapkan API pada
  ContractLens.
- Menanyakan cara mendapatkan token.
- Menanyakan cara menggunakan token.
- Menanyakan bagaimana API terhubung dengan ContractLens Gateway.
- Menanyakan ke mana API request harus dikirim.
- Menanyakan bagaimana API traffic masuk ke ContractLens.
- Menanyakan bagaimana contract dibuat atau tersedia di
  ContractLens.
- Menanyakan bagaimana Contract Snapshot terbentuk.
- Menanyakan bagaimana Contract Analyzer memproses API.
- Menanyakan bagaimana Contract Intelligence digunakan.
- Menanyakan bagaimana cara melihat perubahan API menggunakan
  ContractLens.
- Menanyakan bagaimana cara menggunakan ContractLens AI setelah
  contract tersedia.
- Menanyakan cara meminta compatibility analysis.
- Menanyakan cara meminta impact analysis.
- Menanyakan cara meminta compatibility recommendation.
- Menanyakan input atau langkah apa yang diperlukan untuk mulai
  menggunakan ContractLens.
- Menggunakan pertanyaan seperti "cara pakai", "gimana caranya",
  "mulai dari mana", "harus daftar dulu nggak", "token-nya dari
  mana", "request-nya dikirim ke mana", atau "setelah itu ngapain"
  dalam konteks ContractLens.


Jika conversation history menunjukkan bahwa user sedang berada
di tengah workflow penggunaan ContractLens, gunakan intent ini
untuk pertanyaan lanjutan mengenai langkah berikutnya.

Contoh:

User:
"API-nya udah gue daftarin."

User:
"Terus token-nya gimana?"

→ TEACH_HOW_TO_USE_CONTRACTLENS


User:
"Token udah ada."

User:
"Terus request-nya dikirim ke mana?"

→ TEACH_HOW_TO_USE_CONTRACTLENS


User:
"Contract-nya udah tersedia."

User:
"Terus sekarang gue bisa ngapain?"

→ TEACH_HOW_TO_USE_CONTRACTLENS


==================================================
<EXCLUSION>
==================================================

Jangan gunakan TEACH_HOW_TO_USE_CONTRACTLENS jika tujuan utama
user:

- Hanya ingin mengetahui apa itu, fungsi, atau kemampuan
  ContractLens secara umum.
  → INTRODUCE_CONTRACTLENS

- Hanya memberikan greeting sebagai pengguna baru.
  → GREETING_FIRST_TIMER

- Menyapa atau melanjutkan percakapan tanpa request penggunaan
  yang spesifik.
  → GREETING_ALREADY_KNOW_APPLICATION

- Memberikan API, cURL, URL, HTTP request, atau API artifact
  untuk dianalisis.
  → ANALYZE_API

- Menanyakan apakah perubahan API compatible atau breaking.
  → CHECK_COMPATIBILITY

- Menanyakan dampak perubahan API terhadap consumer.
  → EXPLAIN_IMPACT

- Meminta solusi atau rekomendasi untuk mempertahankan
  compatibility.
  → RECOMMEND_COMPATIBILITY


Jika user bertanya tentang kemampuan ContractLens tetapi tidak
menanyakan bagaimana cara menggunakan kemampuan tersebut,
gunakan:

→ INTRODUCE_CONTRACTLENS


Jika user bertanya bagaimana cara melakukan atau menggunakan
kemampuan tersebut, gunakan:

→ TEACH_HOW_TO_USE_CONTRACTLENS
