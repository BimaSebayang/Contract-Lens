==================================================
<INTENT name="ANALYZE_API">
==================================================

Gunakan intent ini HANYA ketika user memberikan API artifact
atau informasi API yang dapat dianalisis oleh ContractLens.

API artifact dapat berupa:

- cURL
- HTTP request
- API endpoint
- URL API
- Request body
- Response body
- API contract
- API specification
- Informasi API lain yang secara konkret dapat dianalisis.

Jika user BELUM memberikan API artifact atau informasi API yang
dapat dianalisis, JANGAN gunakan ANALYZE_API.

Pertanyaan mengenai apakah ContractLens dapat menganalisis,
memeriksa, atau mengecek API bukan merupakan ANALYZE_API.


==================================================
<RECOGNITION>
==================================================

Gunakan ANALYZE_API jika:

- User memberikan cURL.
- User memberikan HTTP request.
- User memberikan API endpoint atau URL API.
- User memberikan request atau response API.
- User memberikan API contract atau specification.
- User memberikan API artifact lain yang dapat dianalisis.
- User memberikan API artifact dan meminta API tersebut diperiksa,
  dianalisis, atau dipahami.
- User hanya memberikan API artifact tanpa pertanyaan tambahan.

KEBERADAAN API ARTIFACT ADALAH SYARAT UTAMA UNTUK MENGGUNAKAN
ANALYZE_API.


==================================================
<EXCLUSION>
==================================================

JANGAN gunakan ANALYZE_API jika user BELUM memberikan API artifact.

Contoh:

"ContractLens bisa cek API nggak?"
→ INTRODUCE_CONTRACTLENS

"Berarti bisa ngecek beberapa API yang aku punya?"
→ INTRODUCE_CONTRACTLENS

"ContractLens bisa analisis API?"
→ INTRODUCE_CONTRACTLENS

"Apa ContractLens bisa periksa API?"
→ INTRODUCE_CONTRACTLENS

"Gue punya beberapa API, bisa dicek?"
→ INTRODUCE_CONTRACTLENS

"Kalau mau cek API gimana?"
→ TEACH_HOW_TO_USE_CONTRACTLENS


Jika user memberikan API artifact:

"Nih curl gue, coba cek."
→ ANALYZE_API

"Nih endpoint gue: GET /users/123"
→ ANALYZE_API

"Ini request API gue."
→ ANALYZE_API

[User hanya memberikan cURL]
→ ANALYZE_API

[User hanya memberikan HTTP request]
→ ANALYZE_API


Jangan gunakan ANALYZE_API jika tujuan utama user adalah:

- Compatibility / breaking change.
  → CHECK_COMPATIBILITY

- Impact terhadap consumer.
  → EXPLAIN_IMPACT

- Recommendation untuk compatibility.
  → RECOMMEND_COMPATIBILITY
