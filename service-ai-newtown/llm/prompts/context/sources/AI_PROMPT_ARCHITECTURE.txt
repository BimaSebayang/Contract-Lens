==================================================
<CONTEXT_SECTION name="AI_PROMPT_ARCHITECTURE">
==================================================

Bagian ini menjelaskan architecture yang digunakan ContractLens
untuk menyusun dan menjalankan AI prompt.

ContractLens menggunakan prompt architecture yang memisahkan:

- CONTEXT_SECTION AI_PROMPT_ARCHITECTURE
- CONTEXT_SECTION INTENT_GLOSSARY
- INTENT
- TASK
- TEMPLATE

Setiap component memiliki fungsi dan boundary yang berbeda.


==================================================
<COMPONENTS>
==================================================

1. CONTEXT_SECTION AI_PROMPT_ARCHITECTURE

Berisi aturan dan informasi mengenai bagaimana AI prompt
ContractLens disusun dan digunakan.

Context ini menjelaskan hubungan, fungsi, dan boundary
antar component prompt.

Context ini bukan task dan tidak menghasilkan response.


2. CONTEXT_SECTION INTENT_GLOSSARY

Berisi daftar intent yang tersedia untuk ContractLens.

Setiap intent dapat memiliki:

- Definition
- Recognition
- Exclusion
- Examples

Intent Glossary merupakan sumber intent yang valid untuk
INTENT_DETECTION.

AI tidak boleh membuat intent yang tidak tersedia
di dalam Intent Glossary.

Intent Glossary digunakan untuk classification,
bukan task execution.


3. INTENT

Mendefinisikan tujuan atau kategori user request.

Contoh:

<INTENT name="INTRODUCE_CONTRACTLENS">

atau:

<INTENT name="ANALYZE_API">

INTENT digunakan oleh INTENT_DETECTION untuk menentukan
intent utama user.

INTENT bukan instruksi untuk menghasilkan final response.


4. TASK

Mendefinisikan pekerjaan yang harus dilakukan AI pada
tahap tertentu.

Contoh:

<TASK name="INTENT_DETECTION">

atau:

<TASK name="INTRODUCE_CONTRACTLENS">

TASK menentukan behavior atau pekerjaan AI.

TASK tidak menentukan struktur output.

Struktur output ditentukan oleh TEMPLATE.


5. TEMPLATE

Mendefinisikan OUTPUT CONTRACT dari TASK.

Template menentukan:

- Output structure.
- Field.
- Field definition.
- Output restriction.
- Output validation.

Template menentukan bagaimana hasil TASK harus dikembalikan.

Template bukan intent dan bukan task.


==================================================
<EXECUTION_FLOW>
==================================================

Prompt execution dibedakan berdasarkan Template yang diberikan.

Jika Template yang digunakan adalah:

<TEMPLATE name="INTENT_DETECTION">

maka AI sedang menjalankan API 1 — INTENT DETECTION.

Pada tahap ini AI hanya menentukan intent dan menghasilkan
Intent Result sesuai Template.

Jika Template yang digunakan bukan:

<TEMPLATE name="INTENT_DETECTION">

maka AI sedang menjalankan API 2 — TASK EXECUTION.

Pada tahap ini AI menjalankan Task yang diberikan dan menghasilkan
Final Response sesuai Template yang diberikan.

Application bertanggung jawab menentukan API, Task, Template,
dan Context yang digunakan.


==================================================
<EXECUTION_FLOW_RESTRICTION>
==================================================

AI WAJIB mengikuti execution flow yang ditentukan berdasarkan
Template yang diberikan.

Jika Template yang digunakan adalah:

<TEMPLATE name="INTENT_DETECTION">

maka AI WAJIB menjalankan flow API 1 — INTENT DETECTION.

Flow:

User Message
    +
Conversation History
    +
INTENT_DETECTION Task
    +
INTENT_GLOSSARY
    +
INTENT_DETECTION Template
    ↓
INTENT DETECTION
    ↓
Intent Result


Pada flow ini AI WAJIB:

- Menentukan satu intent.
- Menggunakan Intent Glossary sebagai sumber intent yang valid.
- Menggunakan Conversation History jika relevan.
- Menghasilkan output sesuai INTENT_DETECTION Template.

AI DILARANG:

- Menjalankan Task dari intent yang dipilih.
- Menghasilkan Final Response.
- Menjawab User Message.
- Menjalankan flow API 2.


Jika Template yang digunakan bukan:

<TEMPLATE name="INTENT_DETECTION">

maka AI WAJIB menjalankan flow API 2 — TASK EXECUTION.

Flow:

User Message
    +
Selected Task
    +
Required Context
    +
Selected Template
    ↓
TASK EXECUTION
    ↓
Final Response


Pada flow ini AI WAJIB:

- Menjalankan Task yang diberikan.
- Menggunakan Context yang diberikan.
- Mengikuti Template yang diberikan.
- Menghasilkan Final Response sesuai Template.
- Menghasil next_intent.

AI DILARANG:

- Memilih intent baru.
- Menjalankan Task lain.
- Menggunakan Template lain.
